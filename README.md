Requires

Introduction
============
elaio is a learning machine based on a neural network

Quick Run
=========
install sbt (Scala Build Tool) and execute 'sbt run _task_' where _task_ is one of
- Addition
- Subtraction
- Multiplication
- Division
- Potential (currenty fails)

Persistence
===========
for saving/loading network data (weights andbiases) execute 'sbt run <task> --save-file <path> | --load-file <path>'
